## Honest summary

**Mostly inconclusive, not informative, at any strict SESOI.** Only `Specificity_mean_lag` (Model 4) is equivalent to zero within the tighter ±0.10 SD bound — every other term requires the loosest ±0.20 SD bound to establish equivalence, and Model 3's `Corporate_ESG_share_lag` (the largest point estimate in the whole table, std_coef≈0.124) doesn't establish equivalence even at ±0.20 SD — its CI comfortably contains effects that would be considered economically meaningful in this literature. The Bayes factors tell the same story: no term reaches even "moderate" evidence for the null under a tight, skeptical prior (N(0,0.1)); only a diffuse prior (N(0,0.5)) — which itself assumes large plausible effects are unlikely a priori — pushes several terms into moderate support for H0.

**Do not report these results as "we found no effect."** The honest claim, given N=183 and this design's actual precision (MDE ranging 0.09-0.24 SD at 80% power), is closer to: *this design cannot reliably distinguish a true null from a small-to-moderate positive valuation effect of ESG specificity*. That's a real, reportable finding about statistical power, not the same claim as a confirmed null.

## Assumptions and judgment calls made (flagged per instruction)

1. **Key coefficients scope** — Table 5a's four Q-based models chosen as primary; ROE treated as a robustness variant, not a parallel track. See Scope note above.
2. **Standardization convention** — partial standardized effect (coef × SD(x)/SD(y)) on each model's own complete-case sample, not the full 209- or 238-row panel; a different denominator sample would shift these somewhat.
3. **z, not t, critical values** — matches the notebook's own HC3 output convention (`P>|z|`), not a claim that a t-correction would be wrong; with residual df≈147 the difference is negligible (t₀.₀₂₅,₁₄₇≈1.976 vs. z≈1.960).
4. **TOST/verdict bucket bounds (0.10/0.20 SD)** are NOT proposed as your SESOI — they were chosen only to split the seven-line verdict table into three legible buckets, per the worked example in the request. The three SESOI candidates in Step 4 are the actual proposal for you to choose from.
5. **Bayes factor priors** (N(0,0.1), N(0,0.5) on the standardized scale) are exactly the two named in the request — not independently chosen.
6. **Robustness variant (d), dropping ROA** — chosen because ROA is never significant in any model reported in this session; this is a plausible, motivated "remove a non-informative control" check, not an arbitrary one, but it is still a choice among several equally defensible alternative specifications (e.g. region FE instead of company FE was not tried).
